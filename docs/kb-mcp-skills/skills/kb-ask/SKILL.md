## 执行流程

### 1. 确认问答参数

从用户输入中提取：
- `spaceId`（必填）— 不知道时先调用 `list_documents` 获取
- `question`（必填）— 用户的问题
- `sessionId`（可选）— 多轮对话时从上次响应中获取

### 2. 调用问答

调用 `ask_question`：

| 参数 | 必填 | 类型 | 说明 |
|------|------|------|------|
| `spaceId` | ✅ | string | 知识空间 ID |
| `question` | ✅ | string | 问题内容 |
| `sessionId` | ❌ | string | 多轮对话会话 ID，传入上次返回的 sessionId 可延续上下文 |

### 3. 展示结果

- 展示 AI 生成的答案
- 列出引用来源（文档标题、片段摘要、页码）
- **保存返回的 sessionId**，用户追问时传入同一 sessionId

## 多轮对话处理

用户继续追问时（如"那它的配置呢？"、"还有呢？"），自动传入上一次的 sessionId，无需用户重新指定问题背景。

## 失败处理

| 场景 | 处理 |
|---|---|
| 知识库无相关内容 | 告知用户未找到相关文档，建议先上传相关资料 |
| spaceId 不存在 | 调用 `list_documents` 重新获取可用空间 |
