  查看知识库中的文档列表、文档内容和标签分类结构。
  当用户想列出文档、浏览文档、查看某篇文档全文、查看知识库标签分类时使用。
---

## 执行流程

### 1. 判断操作类型

- **列出文档** → 调用 `list_documents`
- **查看文档全文** → 先列出文档获取 `docId`，再调用 `get_document_content`
- **查看标签分类** → 调用 `list_tags`

---

### 2a. 列出文档

调用 `list_documents`：

| 参数 | 必填 | 类型 | 说明 |
|------|------|------|------|
| `spaceId` | ✅ | string | 知识空间 ID |
| `page` | ❌ | integer | 页码，从 0 开始，默认 0 |
| `pageSize` | ❌ | integer | 每页条数，默认 20 |

**展示格式：** 列表展示文档标题、ID、状态（处理中/就绪/失败）、分块数。

---

### 2b. 获取文档全文

调用 `get_document_content`：

| 参数 | 必填 | 类型 | 说明 |
|------|------|------|------|
| `spaceId` | ✅ | string | 知识空间 ID |
| `docId` | ✅ | string | 文档 ID（从 list_documents 结果中获取） |

> 超过 10000 字的文档会自动截断，提示用户内容已截断。

---

### 2c. 查看标签分类

调用 `list_tags`：

| 参数 | 必填 | 类型 | 说明 |
|------|------|------|------|
| `spaceId` | ✅ | string | 知识空间 ID |

**展示格式：** 层级缩进展示标签树（名称、类型、ID）。

---

## 失败处理

| 场景 | 处理 |
|---|---|
| spaceId 不存在 | 重新调用 `list_documents` 获取可用空间 |
| 文档状态为处理中 | 告知用户文档正在向量化，稍后再试 |
| 文档不存在 | 提示用户确认文档 ID 是否正确 |
| 该空间暂无标签 | 告知用户该知识空间尚未创建标签分类 |
